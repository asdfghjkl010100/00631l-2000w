## 📅 第一階段：純前端儀表板（Phase 1）

### 動機
一群朋友合資定期定額投資 **00631L（元大台灣50正2）**，需要一個即時儀表板來追蹤績效。

### 實作
- **技術棧**：純靜態 HTML + Chart.js
- **資料源**：Google Sheets 發布為公開 CSV（無需後端）
- **部署**：GitHub Pages
- **功能**：四頁籤（基本資訊 / 持股比重 / 指數比較 / 歷史淨值）

## 📅 第二階段：加入 LINE Bot 自動推播（Phase 2）

### 動機
手動開啟瀏覽器查看儀表板太麻煩，希望 **Google Sheets 更新時能自動推播到 LINE 群組**。

### 技術演進

#### v1 — Flask + APScheduler（2026-06-13）
- **commit**: `2f559e7`
- 使用 APScheduler 每 5 分鐘輪詢 Google Sheets CSV
- 偵測到資料指紋變更時，透過 LINE Messaging API 推播到群組
- 支援「查詢」指令回覆基金總覽

#### v2 — 精簡功能（2026-06-13）
- **commit**: `c954e37`
- 移除團員查詢、說明等回覆指令
- 只保留「查詢」指令 + 自動推播

#### v3 — 修正 gunicorn 相容性（2026-06-13）
- **問題**：APScheduler 在 gunicorn 環境下排程器未啟動
- **解決**：將排程器啟動移至模組頂層（`commit a99bbb7`）
- **再次解決**：改用 `threading.Thread` 取代 APScheduler（`commit ba40b1f`）

#### v4 — 資訊優化（2026-06-13 ~ 06-14）
- 修正時區為台灣時間 UTC+8（`commit e3810f8`）
- 移除團員概覽，加入上周比較機制（`commit 4aa9564`）
- 推播通知改為顯示完整摘要資訊

#### v5 — 改為每週檢查（2026-06-18）
- **commit**: `d113c62`
- 避免「改一個字就推播一次」的頻繁通知困擾
- 排程改為 **每週日 20:00** 執行一次檢查
- 其他時間修改資料不會觸發推播
- 維持「查詢」指令隨時可手動查詢

## 📅 第三階段：儀表板功能強化（Phase 3）

### 時間
2026-06-16 ~ 2026-06-19

### 改善項目

#### 1. 數字顯示優化
- **FN() 公式**：低於 100 萬顯示完整數字（原為 ≥1 萬就轉萬）
- **Chart tooltip**：7 張圖表懸停提示統一顯示「NT$ xxx萬/億」格式

#### 2. 0050 定期定額比較
- **資料源改善**：Yahoo Finance 改為 query1 → query2 → corsproxy 三層 fallback
- **投入邏輯修正**：改為照 00631L 實際月投入 ÷3 分配至每月 2/12/22 號
- **再簡化**：改為每月 1 號一次投入（長期差異可忽略），並加註說明

#### 3. 版面調整
- **名稱統一**：移除「合資定期定額」前綴，全站統一為「台股國運基金」
- **目標追蹤**：從指數比較移至基本資訊，取代「投入 vs 目前資產比較條」
- **tab 標題互換**：指數比較 ↔ 績效分析，內容與標題對齊
- **團員績效摘要**：從基本資訊移除，改由團員明細頁面查看
- **副標題**：改為「目標總資產一億元」

#### 4. Bug 修正
- **返回總覽**：補上 navOverview 和 backToOverview 的 click 事件綁定
- **殘留程式碼**：移除已刪除元素的 comparisonBar 和 memberSummaryBody JS 參考
- **資料讀取失敗**：修復因上述殘留程式碼導致的 null 錯誤

#### 5. 細節完善
- **預估達成**：加註「(僅供參考)」字樣
- **虧損狀態**：修正為顯示「目前虧損，暫時無法估算」

## 📋 待處理項目（2026-06-19 更新）

### GitHub Pages 部署問題（⚠️ 優先）
`index.html` 已移至 `frontend/` 資料夾。如果 GitHub Pages 設定為從 root 部署，首頁會 404。
需要到 repo **Settings → Pages → Source** 改為「Deploy from a branch」並指定 `frontend/` 資料夾，
或勾選 `docs/` 資料夾（但 docs 裡面沒有 index.html）。
或者**最簡單的方式**：在根目錄放一個 redirect index.html。

### 已處理項目
- `node_modules/` → 已加入 `.gitignore`
- `package.json` / `package-lock.json` → 已加入 `.gitignore`
- `HISTORY.md` → 已建立於 `docs/`（不進 git，僅本機交接用）
- `line_bot/messages.py` → 已 commit 編碼修正

### 建議：根目錄 redirect index.html
如果不想改 Pages 設定，可以在根目錄放一份 redirect：

```html
<!DOCTYPE html>
<meta charset="utf-8">
<meta http-equiv="refresh" content="0; url=frontend/index.html">
<script>location.href="frontend/index.html"</script>
<a href="frontend/index.html">前往儀表板</a>
```

但這樣會多一份檔案在 git 中。

## 🔧 已知限制與建議

| 項目 | 說明 |
|------|------|
| **Render 休眠** | 免費方案在無請求 15 分鐘後會休眠，下次請求需等待 30~50 秒喚醒。可用 UptimeRobot 每 10 分鐘 ping `/health` 解決 |
| **週快照失效** | `weekly_snapshot.json` 存在 Render 本地磁碟，重啟後會清空。未來可改存至 Google Sheets 隱藏分頁 |
| **即時推播** | 目前每週日才檢查一次。如需更即時的通知，可在 Google Sheets 加入 Apps Script 觸發 `/push` 端點 |
| **格式異常** | `messages.py` 曾因編碼問題導致部分字元顯示異常，若遇到亂碼請重新檢查檔案編碼是否為 UTF-8 |
