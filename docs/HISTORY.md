## Phase 1：純前端儀表板

### 動機
一群朋友合資定期定額投資 **00631L（元大台灣50正2）**，需要即時儀表板追蹤績效。

### 實作
- **技術棧**：純靜態 HTML + Chart.js
- **資料源**：Google Sheets 發布為公開 CSV（無需後端）
- **部署**：GitHub Pages
- **功能**：四頁籤（基本資訊 / 持股比重 / 指數比較 / 歷史淨值）

## Phase 2：LINE Bot 自動推播

### 動機
Google Sheets 更新時自動推播到 LINE 群組。

### 版本演進
| 版本 | 日期 | 說明 |
|------|------|------|
| v1 | 6/13 | Flask + APScheduler 輪詢 CSV |
| v2 | 6/13 | 精簡指令，保留「查詢」+ 自動推播 |
| v3 | 6/13 | 修正 gunicorn 相容，改用 threading.Thread |
| v4 | 6/13~14 | 時區 UTC+8、加入上周比較 |
| v5 | 6/18 | 改為每週日 20:00 檢查一次 |

### 部署
- **Render**：託管 Flask Bot（line_bot/）
- 技術：Flask + gunicorn

## Phase 3：儀表板功能強化（6/16~6/19）

1. **數字顯示**：FN() ≥100萬才轉萬，圖表 tooltip 統一格式
